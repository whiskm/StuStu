# StuStu — техническое задание (черновик)

## 1. Что это

StuStu — учебный планер для студента: расписание, домашние задания, экзамены, подготовка, посещаемость, статистика.

Это сайт, который ставится иконкой на главный экран и дальше работает как приложение, в том числе без интернета:

- iPhone — Safari → «Поделиться» → «На экран „Домой“»;
- Android — Chrome → «Установить приложение»;
- Windows — Edge или Chrome → «Установить».

## 2. Откуда берём

Основа — текущий StuStu 2.0: https://muddy-union-c41b.whiskm.workers.dev/stustu/

Из «Зачётки» берём только StuStu. Тренажёры (ОС, cmd, БИУС) в репозиторий не попадают.

## 3. Что сохраняем из 2.0 (всё)

- Главная: текущая пара, отсчёт, следующая пара, отметка посещения, нагрузка на неделю, ближайшие экзамены, срочные ДЗ, заметки.
- Расписание: чередование недель (1–4), время пар, отмена пары на день, каникулы, меню пары.
- Задания: ДЗ и экзамены с целью подготовки.
- Заметки с привязкой к дню, паре, предмету или по расписанию.
- Статистика: посещения, подготовка, задания.
- Таймер подготовки.
- Настройки, тема (светлая / тёмная / как в системе), резервная копия в файл, загрузка из файла, «Поделиться расписанием».

## 4. Этап 1 — что делаем сейчас

1. **Новый аккуратный код.** Те же функции, но код разбит на части, чтобы его можно было развивать дальше.
1. **Новый дизайн и цвета.** Направление «Маршрут дня»: день показан как линия с остановками-парами. Макеты: https://claude.ai/artifact/7Nq4n5fz8soMT5uxyqT6Fk (утверждены). Новая иконка под новый стиль.
2. **Версия для компьютера.** На широком экране — меню слева, больше информации на экране, работа с клавиатуры.
3. **Быстрый запуск без интернета.** Открывается сразу из памяти устройства; если вышла новая версия — плашка «Обновить».
4. **Установка.** Подсказка «Как добавить на главный экран» для iPhone, Android и Windows; иконки, которые не обрезаются на Android.
5. **Календарь телефона.** Выгрузка пар, ДЗ и экзаменов в календарь (файл .ics) — напоминания будет присылать сам календарь.
6. **Переезд данных.** Файл резервной копии из 2.0 загружается в новую версию без потерь.

## 5. Этап 2 — позже

Нужен небольшой сервер (Cloudflare), поэтому отдельно:

- синхронизация телефона и компьютера по коду, без регистрации;
- уведомления: перед парой, о ДЗ и экзаменах, вечерняя сводка.

## 6. Как устроено

- Код: TypeScript + Vite + Preact.
- Хостинг: Cloudflare Pages, подключён к этому репозиторию — после каждого обновления сайт выкладывается сам.
- Данные хранятся на устройстве, в браузере. Формат совместим с 2.0.

## 7. Готово, когда

- Работает всё из раздела 3.
- Файл копии из 2.0 загружается без потерь.
- Ставится на главный экран и открывается без интернета на iPhone, Android и Windows.
- Проверено на экране телефона и компьютера, в светлой и тёмной теме.

## 8. Решено

- Пользователь один, переносить чужие данные не нужно.
- Сайт: Cloudflare Pages подключается к этому репозиторию. Адрес вида `stustu.pages.dev`, его можно поменять позже.
